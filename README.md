**VoidTube** is a modern, dark-themed YouTube client for Android phones and tablets, developed by **VoidXDevs**. It combines a polished glass-inspired interface with powerful playback features, offline downloads, synchronized lyrics and a customizable viewing experience.

## Features

- **Ad-free viewing** — Enjoy videos without traditional advertisements, with SponsorBlock integration for skipping supported sponsor segments.
- **Offline downloads** — Download videos for offline playback, with support for resolutions up to 1080p where available.
- **Background playback** — Keep audio playing with the screen off.
- **Picture-in-picture** — Watch videos in a floating window while using other apps.
- **Synchronized lyrics** — Follow song lyrics line by line with supported providers.
- **Shorts support** — Enjoy a dedicated, full-screen Shorts experience.
- **Enhanced discovery** — Search filters, channel information, and sortable channel videos.
- **Personalization** — Customize the theme, app icon, home layout, navigation tabs and interface.
- **Improved video discovery** — Return YouTube Dislike and DeArrow integrations provide additional context for videos.
- **Account and casting support** — Access subscriptions with supported sign-in methods and cast to compatible devices.

Feature availability may vary depending on the service, provider and device.

|---|---|
| `arm64-v8a` | Most modern Android devices |
| `armeabi-v7a` | Compatible 32-bit Android devices |
| `universal` | Devices where the correct architecture is unknown |

**Requirements:** Android 7.0 (API 24) or later.

## Installation

1. Open the [latest releases](https://github.com/DevXShiva/VoidXTube/releases/latest) page.
2. Download the APK compatible with your device.
3. Open the downloaded file and follow Android's installation prompts.
4. If prompted, allow installation from your browser or file manager.

VoidTube uses its own application ID and can coexist with other YouTube clients.
