## How to read a cell

- `H:` harness (host, signed out, no PO token), one /player + media probes per attempt. The answer was OK and googlevideo served the first bytes of: `A` adaptive video+audio; `P` progressive 360p (itag 18) but not adaptive; `HLS` only HLS; `DASH` only DASH (for `live` the order is DASH > HLS > A > P). `403` = URLs offered but every probe refused through 40 s. `SABR` = OK but no format with a URL (SABR-only or no formats). `REF <code>` = UNPLAYABLE / LOGIN_REQUIRED / ERROR with that reason code. `k/n` = attempts; `[Nv]` = distinct videos when fewer than attempts. `+k net` transport errors (proxy/timeout), `+k bot` bot challenges, `+k err` harness errors — excluded from n.
- `S:` harness sustain (150 s paced HTTP replay with a seek at 90 s; no decoding): `A ok k/n (EOF@120s)` served to the end of the file before 150 s; `A 403@46s` first refusal at playback second 46; `NO-MEDIA SABR` the fresh answer had no URLs; `unsupported` the replay cannot do that delivery.
- `D <build>:` in-app opens on the Pixel (forced source, 150 s with the app's auto-seek). `PLAY` = bench-tick positions advanced to >=140 s of playing time, or to <=10 s from the end / ENDED; `NO-START` = no first frame; `DIED@Ns` = playback stopped at position N s (` 403` = every such open logged HTTP 403 errors); `(answers usable k/n)` = only k of the forced source's own /player answers had usable adaptive formats. Not verdicts: `aborted` (a phone event took focus), `no-data` (the open's log had no /player result for the video), `bot-cooldown` (the app's bot-check cooldown answered without any /player), `short-run` (a 15 s test cell, still playing when it ended). `ff` = median open → first frame over the verdict opens (PLAY, NO-START, DIED). `ring:` = answers this client gave inside the app's own ring walks (`RING[...]` rows), classified from the app's `player-result` lines: `usable` = usableAdaptive>0, `SABR` = OK with usableAdaptive=0, `BOT` = explicit bot text.
- Builds: `pre-gate` = app1*/app1b* runs, before the readiness gate (DESIGN §6); `vN` = the check build named in the appbench run script (`check build vN` comment or a `-vN` run id). Builds change the ring, so each `RING[...]` row is one build/profile; the clients each walk asked are listed in "Device opens in detail".
- Categories: `ord` ordinary VOD: vlog, tech, official/vevo music video, dubbed multi-audio, topic art track, 4K60 HDR / 10 h / 360, Shorts, "history" Tiny Desk videos (0e3GPea1Tyg, 5KLPxDtMqe8, BGQWPY4IigY, Fo89b8zAIE4, LXb3EKWsInQ, MT8tg5b3b8E, MgNrAu2pzNs, Vop-h-u9B4o, X1bx9_TL20A, dQw4w9WgXcQ, jNQXAC9IVRw, kJQP7kiw5Fk, p7YpVl35pac, u_vnA6nlDvs, wE-aQO9XD1g); `emb-off` ordinary VOD whose owner disabled embedding (MeJVWBSsPAY, s5qx1X78ujE); `kids` made_for_kids=true, whatever the corpus category (717IVcyUrNE, 9DqETNOlcDE, Fc5aA77Nlf0, KUcmvVHh_RA, XqZsoesa55w, _WB5hh7WOb4, e_04ZrNroTo, gDcYk-rDY5I, pZw9veQ76fo, wGltuo1B1sM); `age-emb` age-restricted 18+, embeddable (HtVdAasjOgU, WaOKSUlf4TM); `age-no-emb` age-restricted 18+, not bypassable (corpus expects a failure) (qkO6iBwcoe4); `live` live now (24/7 stream) (5yx6BWlEVcY); `upcoming` scheduled, not started (j9epFget1W8); `replay` ended live stream with replay (not made for kids) (v03RjDNwG1o); `terminal` private, removed, members-only, paid, region-blocked, dead stream, premium-only (6SJNVb0GnPI, 6ULI7RH_0U8, EwVsbUg4u2I, X4VbdwhkE10, XclachpHxis, jfKfPfyJRdk, jwCz9KmGuYY, sJL6WA-aGkQ, w664JpkrDio, yZIXLfi8CZQ)
